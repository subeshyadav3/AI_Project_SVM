How it works

  1. Face detection — YuNet (or Haar fallback) finds all faces, filtered by threshold & minimum pixel size.
  2. Crop + pad — Each face is padded 15% and resized to 224×224.
  3. Feature extraction — ResNet18 (layer4 fine-tuned) extracts 512-D features, scaled by StandardScaler.
  4. SVM — RBF SVM (C=0.01, gamma=scale) predicts Male / Female with confidence.

Model accuracy: 91.9% • Trained on UTKFace 24k images with orientation augmentation (±15° rotation, affine, perspective).
